EvoEnv · verifiable environment architecture

Don’t generate questions. Generate a world factory.

One executable environment contains four routines: sample an instance, compute its hidden answer, render the prompt, and score the response.

VISIBLE MODEL PATH
HIDDEN CODE PATH · NEVER SHOWN TO THE LLM
sample()Create a fresh latent task instance z.
render()Turn z into the prompt the model sees.
oracle() LOCKEDCompute the reference answer in Python.
LLM solverReceives only the rendered prompt.
hidden referenceTravels only through the code path.
score()Compare response y with reference y*.
R0 or 1
POOL ADMISSION · STARTING FROM 10 SEEDS
CANDIDATE PYTHON ENVIRONMENT
EXECUTABLE?Interface and runtime checks pass.
SEMANTICALLY CORRECT?Self-review rejects broken tasks.
HARD ENOUGH?Solver rollouts calibrate difficulty.
NOVEL?Reject near-duplicates of the pool.
ACCEPTED → RL ENVIRONMENT POOL
This—not a static dataset—is the training source. Once accepted, one environment can emit unlimited fresh instances with deterministic hidden rewards.
